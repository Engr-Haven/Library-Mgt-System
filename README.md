# PROJECT TITLE & DESCRIPTION

## LIBRARY MANAGEMENT SYSTEM

### A secondary school in Lagos wants to replace their manual library book log with a simple browser-based system. The goal is to allow **librarians** to record, search, and manage books easily, while **students** can check if a book is available. The system should be secure and easy to use, with a user-friendly interface.
